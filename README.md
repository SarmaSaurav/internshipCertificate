# Cotton University Internship Certificate Generator

A simple, completely offline HTML/CSS/JavaScript application for generating
A4 internship completion certificates for the Department of Statistics,
Cotton University.

## Requirements

None.

No Node.js, Python, server, database, or internet connection is required.

## Run

Simply double-click:

    index.html

It will open in your browser.

## Logo

Place the official Cotton University logo at:

    assets/cotton-university-logo.png

If the file is absent, the application displays a small "CU" placeholder.

## Generate PDF

1. Fill in the certificate details.
2. Check the A4 preview.
3. Click "Print / Save PDF".
4. Select "Save to PDF" in the browser print dialog.
5. Use A4 paper size and 100% scale.

The application already contains print CSS for an A4 portrait page.

## Local storage

The form data is automatically saved in the browser's localStorage.
This allows multiple certificates to be generated without re-entering
all settings.

No student information is transmitted anywhere.
